# Dealership Application

### By Abdul Tareq Khaliq

---

## About
The **Dealership Application** is a CLI based Python application where customers can login and buy cars from the dealer's inventory.

### Key Features:
- **Inventory Management:** As an Admin you can asily add, update, and remove vehicle entries.
- **Orders:** As an admin you can view all the orders of all the users.
- **Customer capabilities** As a customer you can purchase cars and view owned cars, orders
- **User-Friendly Interface:** Built for ease of use and minimal learning curve.

---

## How to Run the Application

### Prerequisites
Ensure you have the following installed:
1. **Python 3** 
2. **MongoDB** for database
3. A compatible **IDE** (e.g., IntelliJ IDEA, Eclipse) or a terminal with proper configurations

### Steps to Run
1. Clone the Repository
  

2. Import dependencies Make sure to install pymongo, bcrypt and logging by running:
3. pip3 install bcrypt
4. pip3 install pymongo
5. pip3 install bcrypt


6. Run the Application
   Command: python app.py
